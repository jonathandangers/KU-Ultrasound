# KU Emergency Medicine Ultrasound Rotations (Prototype)

Standalone interactive prototype built from the current rotation Google Site (`sites.google.com/view/ultrasoundrotationhome`).

- **Live site:** https://jonathandangers.github.io/KU-Ultrasound/
- **Included in prototype:** Home screen (Calm Light/Dark + optional 8-Bit mode), full Medical Student Rotation track (Schedule & Duties, interactive 200-scan tracker, 26-item Butterfly module checklist, GE Venue Go 10-step guide, Qpath troubleshooting, Vascular Access rules, and Syllabus/Deliverables).
- **Zero external dependencies:** Single self-contained `index.html` with inline CSS and JS.
